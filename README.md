## 3. 作業問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**
* **回答**：在 Python 中，加上引號的 `"4"` 是**字串（`str`）**型別，代表的是文字符號而非數學上的數量；而應付總額是**浮點數（`float`）**。Python 不允許將「數字」直接除以「字串」（執行 `1220.0 / "4"` 會直接觸發 `TypeError` 型別錯誤而導致程式崩潰），因此必須先用 `int("4")` 將其轉換為整數 `4`，才能進行除法運算。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
* **回答**：若先扣折價券再算服務費，第一組的應付總額會變成 **1,210 元**（比原本的 1,220 元少了 10 元）。
* **計算過程**：
  1. 先扣折價券：$1200 - 100 = 1100$ 元
  2. 以剩餘餐費計算 10% 服務費：$1100 \times 0.10 = 110$ 元
  3. 應付總額：$1100 + 110 = 1210$ 元
* **原因說明**：這反映了數學上的乘法對減法分配律。因為服務費率（10%）計算的「基準（母數）」不同，先扣折價券會讓這 100 元的折價金額也連帶免除了 10% 的服務費（$100 \times 0.10 = 10$ 元），因此總金額會少 10 元。題目規定服務費必須以「原始餐費」為基準計算，才符合一般餐廳的計費邏輯。
